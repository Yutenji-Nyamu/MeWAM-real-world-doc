暂时按任务作用安排：放盒子提供普通放置参照；抽屉涉及边界、相对位置和遮挡；积木涉及多个目标与连续阶段；插接涉及相对姿态、对齐和接触。最终难度随实物开口、配合公差和成功定义确定。

WAM4D 的 Plate/Bottle/Blocks/Pen 与此对应的是基础操作、避碰、颜色与长时序、精细双臂接触四种要求。几何方法与任务的联系应落到这些实际要求，再用逐任务数据检验。

## 4. 最小数据准备增量

1. 扩展相机采集，保存固定主视角 depth、RGB 对齐规则、出厂 K、深度单位和相机时间戳／frame ID。
2. 沿用双视角 RGB、RTDE 关节／TCP、夹爪、episode 与结果；明确训练 action 从未来状态派生的时间对应。
3. 小批片段生成前景／角色 mask、RAFT 光流与 UVD，逐帧检查遮挡、深度孔洞、静止目标结构。
4. 对齐单臂动作槽位、两物理视角与模型视角键；按 episode 固定训练列表。
5. 为训练与评估保存物体、桌布、干扰物和初始位置条件 ID。

对应解释见 [数据与标定](05_data_and_calibration.md)。
