## 任务与指令

| 任务 | 本轮草拟指令 | 完整终点 |
|---|---|---|
| 放入抽屉 | 拿起物体并将其放入抽屉。 | 物体稳定置于抽屉内。 |
| 放进盒子 | 拿起物体并将其放入盒子。 | 物体稳定置于盒内。 |
| 积木分类 | 将所有积木放入颜色对应的容器。 | 所有积木进入对应容器。 |
| 插接 | 将插接件插入对应孔位。 | 插接件完全插入目标孔位。 |

颜色分类与插接件措辞供后续实物核对；示范量、ID/OOD 的试次分配在确定后补齐。
